# Canva-style studio

An unofficial Canva-inspired design studio. It is not affiliated with Canva.

**Live site:** https://iqraaslam2207-collab.github.io/canva-pro/

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## What you can do

- Browse a Canva-style homepage, then log in locally (name is saved in this browser only)
- Start from a format (post, story, presentation, poster, logo, doc, card) or a template
- Drag, resize, and rotate text, shapes, and photos
- Edit text, fonts, color, opacity, radius, and shadow
- Use a brand kit, layers, backgrounds, and magic resize
- Add pages, present them, and download a PNG
- Designs are saved in this browser

## Stack

React, Vite, and Tailwind CSS.
